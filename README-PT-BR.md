# Limpeza de Cache do Windows e Navegadores

**Versão:** 1.0.0  
**Idiomas da interface:** PT-BR, inglês, espanhol, francês, alemão, italiano, japonês, coreano, chinês simplificado e russo. O programa detecta a região do Windows automaticamente e usa PT-BR para regiões não listadas.

## O que faz

Limpeza por clique de arquivos temporários selecionados do Windows e caches de navegadores.

## Arquivos

Windows-Cache-Cleaner.bat

## Como usar

1. Baixe ou clone o repositório completo.
2. Execute `Windows-Cache-Cleaner.bat`. Revise as mensagens; os navegadores devem estar fechados para limpar seus arquivos temporários.

## Requisitos

Windows 10 ou Windows 11 com PowerShell 5.1 integrado. O único arquivo distribuído é `Windows-Cache-Cleaner.bat`; ele mantém a tela no mesmo console preto do CMD.

## Segurança e limitações

O projeto não deve apagar dados pessoais, credenciais ou conteúdo fora dos caminhos definidos pela ferramenta. A disponibilidade de comandos e recursos depende da edição e versão do Windows. Revise CHANGELOG.md antes de atualizar.

## Desenvolvimento

Consulte AGENTS-PT-BR.md e AGENTS-EN.md. O idioma padrão da interface é detectado pela cultura do Windows; quando ela não for compatível, use PT-BR como fallback.

## Idioma automático e dicas

A interface detecta PT-BR, inglês, espanhol, francês, alemão, italiano, japonês, coreano, chinês simplificado e russo pela região do Windows. Feche os navegadores antes da limpeza; histórico, favoritos, senhas, cookies e sessões são preservados.

## Idiomas, finalidade e dicas

A interface está disponível em PT-BR, inglês, espanhol, francês, alemão, italiano, japonês, coreano, chinês simplificado e russo. O idioma é detectado pela região do Windows; PT-BR é o fallback.

Feche os navegadores antes da limpeza. Histórico, favoritos, senhas, cookies e sessões são preservados; arquivos em uso podem ser ignorados.
