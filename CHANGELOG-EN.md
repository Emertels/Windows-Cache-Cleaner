# Changelog

## 1.0.0 — 2026-10-09

- Updates the run instructions to point directly to the correct project entry point.

- Cleans only explicitly defined temporary and cache folders.
- Preserves browser history, bookmarks, passwords, cookies, and sessions.
- Skips open browsers and summarizes removed or skipped items.
- Provides one-click launch, localized interface, and colored summary.
- Converts the program to a single `.bat` with eight CMD-style stages and no second window.
- Expands temporary browser and GPU cache coverage; preserves personal data and skips open browsers.


- Corrects accents and cedilla in interface text and documentation, aligns session headers, and updates agent instructions.

- Usage, dependency, and required-file documentation was reviewed to match current project behavior.

- Aligns the author, projects, and official communities section with the Antigravity reference repository.
